## Facility-profile responsive fix (2026-11-14T19:14:38Z)

The facility profile's source-evidence table has a 56rem minimum table width. On a 412px
mobile viewport that min-width propagated through the grid item and expanded the page's
layout viewport to 923px, so the page rendered zoomed out and text was clipped. The
"At a glance" sidebar also reused the 12rem label grid inside a 20rem card, squeezing
values such as "Active in Registry" into a narrow column.

Fixes:
- `min-w-0` on the content grid column and sidebar so their min-content width cannot
  expand the page; the existing `table-scroll` region now owns horizontal scrolling.
- `min-w-0 break-words` on definition values.
- Stacked sidebar rows via a `stacked` DataRow variant.

Browser measurement after the fix (Playwright Pixel 7, 412px viewport):
innerWidth=412, documentElement.scrollWidth=412, source-evidence region clientWidth=361,
region scrollWidth=896 (internal scroll only).

Playwright regression added: "facility profile › keeps wide tables inside their own
scroll region on mobile" (mobile project; intentionally skipped on desktop).

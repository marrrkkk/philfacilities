Problem
-------
The retained release PHILHEALTH-EMCB-ANTE_093026-2026-09-30 said
row_count_parsed = NULL, ingestion_status = failed, publication_status = blocked,
while its latest ingestion run said status = published with 6,562 parsed and
accepted rows, 6,168 accreditations, and 394 skipped duplicate source rows.
The dataset still said publication_status = published even though no Antenatal
source records, accreditations, or facility links remained.

Cause
-----
The PDF is a two-up landscape print. Pages 1-120 contain the provider columns;
pages 121-240 contain only the aligned EXPIRE DATE and SEC annex. The first
successful parse counted the annex pages as additional provider rows, producing
6,562 parsed rows. A later post-ingestion review removed all derived records and
blocked the release. The raw PDF was retained unchanged.

Corrected re-parse
------------------
The parser was corrected to read only provider pages and merge the aligned
expiry/sector annex (parser version bumped to philhealth-pdf-1.2.0). Re-parsing
the retained raw file yields 3,221 provider rows and zero rows from pages 121+.
No Antenatal data is published until a validated re-ingestion.
